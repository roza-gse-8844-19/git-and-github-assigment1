# Git and GitHub Fundamentals

A project showing essential Git commands, GitHub workflow, and basic Python programming concepts.

## Project Overview

This project was created to practice version control with Git, manage a local repository, and prepare a project for sharing on GitHub. It also includes a Python script that demonstrates fundamental programming concepts.

## Project Structure

```text
git-github-assignment/
├── README.md
└── first_code.py
```

| File | Description |
|---|---|
| `README.md` | Project documentation and Git workflow |
| `first_code.py` | Examples of basic Python programming concepts |

## Python Concepts Covered

The `first_code.py` script demonstrates the following concepts:

- **Variables and data types:** Storing and working with strings, integers, floats, and booleans.
- **User input:** Collecting information using the `input()` function.
- **Counting:** Using `len()` to count characters and words.
- **String methods:** Using `split()` to divide a sentence into words.
- **String slicing:** Extracting parts of a string using slice notation.
- **Conditional statements:** Using `if-else` to make decisions.
- **Type checking:** Using `type()` to identify the data type of a value.

## Git Workflow

The project follows a basic Git workflow:

1. Configure the Git username and email.
2. Create a project directory.
3. Initialize a local repository using `git init`.
4. Create and edit the Python script.
5. Check file changes using `git status`.
6. Stage files using `git add`.
7. Save changes using `git commit`.
8. Review the commit history using `git log`.
9. Document the project in `README.md`.
10. Connect the local repository to GitHub using `git remote`.
11. Upload the commits to GitHub using `git push`.

## Useful Git Commands

| Command | Description |
|---|---|
| `git init` | Initializes a local Git repository |
| `git status` | Displays the current repository status |
| `git add -A` | Stages all changes |
| `git commit -m "message"` | Creates a commit with a descriptive message |
| `git log --oneline` | Displays a concise commit history |
| `git remote -v` | Lists configured remote repositories |
| `git push -u origin main` | Pushes the `main` branch to the remote repository and sets its upstream |
